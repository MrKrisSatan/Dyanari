What stays with us

Memory belongs to Dyanari and is shared across all chat models. Switching models preserves saved memories, personality and stored conversations. Project boundaries and private-session rules still apply.

Memories are editable and use local semantic retrieval. Begin a message with “Remember that …” to store an explicit fact. Project memories are recalled only in the selected project; unlabelled memories are shared.

Repositories, builds & tests

        
Enable Tools & File Access, Read Files and Run Tools first. Approve workspace folders in Tools & permissions. Every command, local Git change and GitHub write requires a fresh preview approval.

        
        
        
        

        
GitHub account and repositories

          
Use “Dyanari - Connect GitHub” in the Windows Start menu to sign in with the bundled official GitHub CLI. Source users can use Git Credential Manager or gh auth login. Tokens are never stored in Dyanari's memory or shown to the chat model. The bundled GitHub CLI shares its account login with other GitHub CLI installations.

          

          
          
          
          
          

          
Ask Dyanari to clone a repository, create a branch, commit named files, pull, push, list issues, or prepare an issue/comment/pull request. HTTPS github.com origins only; force pushes, resets, merges with conflicts and automatic conflict resolution are unavailable.
