# Dyanari 0.8.0 — VoiceStudio and Velvet British

VoiceStudio is integrated as a separate local service, including optional in-app installation/repair, service lifecycle, voice/profile and engine selection, designed voice creation, identity preview, speech, reviewed WAV transcription, and opening the full upstream studio. Its advanced design/cloning/dubbing/audiobook/model interfaces remain available in the full studio; individual optional engines/providers and advanced production jobs have not all been acceptance-tested.

Dyanari's new Velvet British design uses an adult female British accent, low pitch, whisper/breathy delivery, a fixed seed and a saved identity sample, at 0.92 speed. Supported engine attributes drive generation; the stored prose description does not make OmniVoice understand unsupported emotional/timbre instructions. Preview and refine the sound to taste. Profile/engine/speed persist independently of the chat model.

The isolated, pinned setup installs VoiceStudio 0.5.7 source/backend/full web UI, CPU PyTorch, uv/Bun lockfile dependencies and optionally pinned OmniVoice plus Whisper base weights. All executable/source archives are SHA-256 verified. There is no global Python package installation. VoiceStudio source, licence and notices are retained under the private runtime folder. Public installers leave the feature OFF and model acceptance unset. Model weights are not redistributed. See [setup, model terms and limitations](VOICESTUDIO.md).

Managed inference uses exact local voice weights and offline Hugging Face/Transformers flags on CPU, avoiding contention for the 8 GB NVIDIA GPU. It can be slow. Enabled/selected VoiceStudio starts again on app launch; Windows speech remains available. The full studio is independent software with its own history, permissions and optional networking. Dyanari's Internet switch is not an OS firewall.

Stop/revocation/settings cancellation terminates owned synthesis/service process trees; Internet revocation terminates owned setup. External services remain untouched and may finish upstream compute after a request is cancelled. Private-session speech is rejected for VoiceStudio; select Windows speech instead. WAV transcription is explicitly uploaded and reviewed, with no microphone activation or automatic chat submission. Memory-backup restore disables VoiceStudio and selects Windows speech; voice samples/runtime weights need a separate directory backup.

Verification: 10 voice unit tests; authenticated voice HTTP acceptance for permissions/private omission/actual WAV delivery/model-independent profile/restore/external-service preservation; actual pinned source installation and full web build; real OmniVoice speech and identical saved identity after managed-service restart; actual Whisper base transcribed the generated preview as “Good evening, I'm Dianari. Take your time, darling. I'm right here with you.” This checks intelligibility, not subjective voice appeal. Existing regression and optional-service tests total 101 passing tests. Development/MCP, memory and task HTTP acceptance also pass. Packaged payload and installer checks are recorded in BUILD-INFO.json.

Windows 10/11 x64; unsigned preview. Clean-machine installation, microphone/device selection, GPU voice acceleration and every optional upstream engine remain unverified. These stay open in [TODO.md](TODO.md).
