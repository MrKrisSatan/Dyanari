# Dyanari 0.9.0 — Qwen images, optional inspiration and a fuller British voice

The installer now offers optional hardware-selected Qwen Image 2.1 bundles alongside text-model selection. Selection considers total RAM, NVIDIA VRAM, encoder/projector/VAE overhead and download size. Pinned source archives, frozen Python dependencies and model hashes provision a separate local ComfyUI/GGUF runtime. The Qwen Research License is shown before download; consent and installation default OFF. Weights are separate downloads.

Requested chat images use a real `generate_image` tool with only a prompt required, installed-bundle defaults, correct 2.1 conditioning/VAE and actual PNG delivery to chat and the artwork library. Explicitly opted-in spontaneous images use the local model's decision/prompt, a user-selected theme, quiet hours, daily quotas, cooldown, idle admission and persistent Stop pause. Private chats/screens/memories are not inputs to that scheduler. Existing file/tool effects, including requested artwork, still persist independently of private chat storage.

On a 16 GB RAM / RTX 3060 8 GB workstation, both Q2 and Q4 completed real 512×512, 25-step renders; Q4 is now recommended there and Q2 remains the smaller fallback. An actual Qwen3 4B Instruct idea produced a real Q4 image and consumed its daily quota without adding chat memory. Higher tiers are selection estimates, not measured hardware claims. CPU startup was checked; full CPU/AMD rendering and clean-machine setup are unverified. See [image setup and limits](QWEN-IMAGE.md).

Dyanari's new **British Velvet** voice replaces the whisper attribute with a mature, low British female design and fully voiced delivery, at 0.94 speed. Its description aims for a warm, smoky, confident British Jessica Rabbit character style; OmniVoice's limited tags do not guarantee a particular timbre or character performance. A new fixed-seed identity was actually rendered and selected locally; the previous whisper voice remains available. Public defaults use the new design when creating a voice, without pre-accepting model terms. See [voice guide](VOICESTUDIO.md).

Verification: 17 new image unit tests, authenticated image/chat HTTP acceptance, existing regression/service suites, actual pinned Qwen installs/renders/spontaneous flow, revised real speech and packaged payload/installer checks. Final counts/hashes are in BUILD-INFO.json. The Windows installer remains an unsigned preview; this release does not finish the full brief.
